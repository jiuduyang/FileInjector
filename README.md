 文件随机注入隐藏工具

 一、工具简介

文件随机注入隐藏工具是一款专为MC整合包制作者设计的轻量级桌面应用，用于将指定标记文件批量随机注入至目标文件夹内不同子目录，实现文件隐藏与版权标记。工具采用现代化GUI界面，操作简单直观，无后台服务、无自启动、无联网、无插件依赖，运行流畅、体积小巧，是整合包作者保护作品版权的理想工具。

 二、核心功能特性

 1. 基础功能
文件注入：支持将单个源文件批量复制到目标目录的不同子文件夹
随机重命名：自动生成6位随机数字文件名，避免重名覆盖
自定义配置：支持设置注入数量、文件名前缀和后缀
实时进度：注入过程中显示进度条和状态信息，无卡死现象

 2. 日志功能
文件隐藏位置日志：记录每一份注入文件的完整路径和修改后的文件名
程序运行日志：记录执行状态、执行时间、注入成功/失败数量等信息
自动生成：日志文件自动保存至目标根目录，编码为UTF8，无乱码

 3. 附加功能
模式切换：支持浅色模式与深色模式自由切换
快捷操作：一键打开目标目录和日志目录
操作控制：支持注入过程中手动停止操作
表单重置：一键清空所有输入和选择
清理功能：根据日志文件一键删除所有注入的文件

 4. 技术特点
轻量级：无冗余功能，启动速度快，占用系统资源极低
跨平台：基于Java开发，支持Windows、Linux、macOS等系统
无依赖：仅需Java 8或更高版本，无需其他第三方库
安全可靠：仅执行复制写入操作，不修改、不删除原有文件

 三、系统要求

操作系统：Windows 7/8/10/11（64位或32位）
Java环境：Java 8或更高版本
硬件要求：最低1GB内存，50MB空闲磁盘空间

 四、详细使用步骤

 1. 启动工具
方法一：双击 `run.bat` 脚本（需要Java环境）
方法二：双击 `dist\FileInjector.exe` 文件（已打包的可执行文件）

 2. 基本操作流程
1. 选择源文件：
    点击"源文件"右侧的"浏览..."按钮
    在文件选择对话框中选择要注入的文件（支持任意格式）
    确认后，源文件路径会显示在输入框中

2. 选择目标目录：
    点击"目标目录"右侧的"浏览..."按钮
    在文件夹选择对话框中选择目标根目录（程序会遍历其所有子目录）
    确认后，目标目录路径会显示在输入框中

3. 设置注入参数：
   注入数量：在"注入数量"输入框中输入要注入的文件份数（默认10）
   文件名前缀：在"文件名前缀"输入框中输入自定义前缀（可选，如 `copyright_`）
   文件名后缀：在"文件名后缀"输入框中输入自定义后缀（可选，如 `_2026`）

4. 开始注入：
    点击"开始注入"按钮
    观察进度条和状态信息，了解注入进度
    注入完成后，会弹出提示框显示成功和失败的数量

5. 查看日志：
    注入完成后，在目标目录中会生成两份日志文件：
      `文件隐藏位置日志.txt`：记录每一份注入文件的完整路径
      `程序运行日志.txt`：记录执行状态、时间和统计信息
    点击"打开日志目录"按钮可直接打开目标目录查看日志

6. 清理注入文件：
    点击"清理注入文件"按钮
    在确认对话框中点击"是"
    工具会根据日志文件删除所有注入的文件
    清理完成后，会弹出提示框显示成功和失败的数量

 五、高级功能使用

 1. 自定义文件名
前缀+随机数+后缀+扩展名：例如设置前缀为 `mc_`，后缀为 `_pack`，源文件为 `logo.png`，生成的文件名为 `mc_123456_pack.png`
仅随机数：如果前缀和后缀都留空，生成的文件名为 `123456.png`

 2. 深色模式切换
 点击界面右上角的"深色模式"/"浅色模式"按钮可切换界面主题
 深色模式适合夜间使用，减少眼部疲劳

 3. 注入过程控制
 点击"停止"按钮可在注入过程中安全停止操作
 已执行的注入会保留，未执行的会终止

 4. 快捷操作
打开目标目录：快速定位到注入的目标文件夹
打开日志目录：快速查看生成的日志文件

 六、注意事项

1. 子文件夹数量：目标目录下的子文件夹数量必须大于或等于注入数量，否则会提示"目标目录下的子文件夹数量不足"
2. 写入权限：确保目标目录有写入权限，否则可能导致注入失败
3. 系统目录：程序会自动跳过系统目录和隐藏目录，避免破坏系统文件
4. 文件大小：注入的文件大小应适中，避免因文件过大导致注入时间过长
5. 日志文件：清理功能依赖于"文件隐藏位置日志.txt"文件，请勿手动修改或删除该文件
6. Java环境：运行工具需要Java 8或更高版本，若未安装会提示错误信息

 七、常见问题与解决方案

 1. 注入失败怎么办？
 检查目标目录是否有写入权限
 检查目标目录下的子文件夹数量是否足够
 检查源文件是否存在且可访问

 2. 清理功能无法删除文件怎么办？
 检查文件是否被其他程序占用
 检查是否有足够的权限删除文件
 检查"文件隐藏位置日志.txt"文件是否存在且未被修改

 3. 工具启动失败怎么办？
 检查Java环境是否正确安装
 检查Java版本是否为8或更高
 检查系统是否有足够的内存和磁盘空间

 4. 日志文件乱码怎么办？
 工具生成的日志文件编码为UTF8，使用记事本或其他支持UTF8的文本编辑器打开
 避免使用旧版的文本编辑器（如Windows记事本的旧版本）
